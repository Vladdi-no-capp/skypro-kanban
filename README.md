# Skypro Kanban

Учебное React-приложение для ведения задач в формате канбан-доски.

## Запуск

```bash
npm install
npm run dev
```

После запуска Vite выведет локальный адрес приложения.

## Маршруты

- `/login` — вход;
- `/register` — регистрация;
- `/` — доска задач;
- `/new-card` — создание задачи;
- `/card/:id` — просмотр и редактирование карточки;
- `/exit` — подтверждение выхода;
- любой неизвестный адрес — страница 404.

Доска и модальные маршруты защищены. В демонстрационной версии вход и
регистрация принимают любые заполненные данные, а состояние авторизации
хранится только в `useState` до перезагрузки страницы.

## Проверка
